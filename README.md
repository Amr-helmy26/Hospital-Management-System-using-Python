# Hospital Management System

A Python-based Hospital Management System designed to simplify the management of patients, doctors, appointments, and billing operations. The project provides a console-based interface that demonstrates fundamental programming concepts and data management techniques.

## Features

### Patient Management

* Add new patient records.
* Store patient details such as:

  * Name
  * Gender
  * Age
  * Address
  * Disease
  * Chronic Diseases
* View all registered patients.
* Search for a patient using their unique ID.

### Doctor Management

* View available doctors.
* Display doctor information including:

  * Name
  * Experience
  * Phone Number
  * Specialty
  * Schedule

### Appointment Booking

* Book appointments between patients and doctors.
* Maintain reservation records for each doctor.
* View doctor schedules and assigned patients.

### Billing System

* Generate patient bills.
* Calculate consultation fees and laboratory costs.
* Display detailed billing information and total cost.

## Technologies Used

* Python
* Dictionaries
* Lists
* Loops and Conditional Statements
* Pattern Matching (`match-case`)
* Console-Based User Interface

## Project Structure

The system is built around four main components:

1. **Patient Management**

   * Registration
   * Search
   * Record Viewing

2. **Doctor Management**

   * Doctor Information
   * Schedule Management

3. **Appointment System**

   * Reservation Tracking
   * Patient Assignment

4. **Billing System**

   * Fee Calculation
   * Bill Generation
